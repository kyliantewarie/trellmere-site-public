Standalone software

Stop drawing the same hole table twice.

DraftForge turns a plain part spec into a complete manufacturing drawing package: layered DXF, SVG, PNG, a hole schedule and an HTML inspection report. One command, no CAD licence, no cloud.

What it does

  • True-value dimensions generated from the same coordinates that draw the geometry.
  • Six named DXF layers: CUT, HOLES, DIMS, GDT, TITLE and NOTES.
  • Hole grids, bolt circles, hole tags and a CSV hole schedule in your own units.
  • ASME/ISO-style feature-control frames, notes and a revision title block.
  • Design checks for edge distance, hole pitch, material web and duplicate holes.
  • Vector PDF, SVG and PNG previews alongside the DXF and hole CSV.
  • Advanced editor for arbitrary holes, dimensions, GD&T and DXF outline import.
  • Scriptable CLI for batch work plus a modern dark desktop app with live preview.
  • Validated with a 200-persona workflow simulation covering every output format.
  • Offline HMAC licence keys — no telemetry, no licence server, no machine fingerprinting.
Why a generator? DraftForge generates the drawing you would otherwise assemble by hand: dimensions, hole tables, feature-control frames and a title block from values you already have.

Proprietary commercial licence, full Python source included. Flat parts, DXF R12. Not a certified inspection record or building-code approval — check outputs before cutting.

Verify it yourself

The download includes a demo spec and a verification log. Run python -m draftforge.cli demo --out out/ and compare the six generated files. 137 automated tests, a 200-persona simulation (4,805 checks) and 17 shipped-package checks passed before packaging.
