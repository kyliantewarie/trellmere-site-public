PLCnext Control · Function extension

Run a real monitoring stack on a 512 MB controller.

Standard Docker images consume 600 MB+ and wear out controller flash. EdgeStack is tuned for the AXC F hardware: the whole stack stays under 280 MB, writes to external storage, and installs with one command.

What is inside

  • Multi-arch Docker Compose stack — Mosquitto, Node-RED 3.1, InfluxDB 1.8 and Grafana 10.4, tuned with low-RAM limits, flash-safe sync intervals and retention policies.
  • ISA-101 situational-awareness dashboard — high-contrast grayscale, colour reserved for abnormal states, live OEE, trends and controller diagnostics.
  • Node-RED flow package — OPC UA, Modbus, PLCnext GDS connector templates, OEE engine, downtime alert dispatcher and a Modbus TCP server gateway.
  • Deployment and recovery scripts — SD-card setup, Docker data-root relocation, swap/OOM tuning, one-command installer, health check, backup and restore.
  • Modbus register map and 10-page field manual — architecture diagrams, memory tables, wiring guides and a troubleshooting matrix.

Verification status

Static configuration, flow logic, simulator and hardware-simulation layers are documented in VERIFICATION.md. The runtime smoke test runs on a GitHub-hosted runner. Hardware commissioning is the buyer's responsibility — this is a simulated, not hardware-validated product, and is deliberately framed that way.

Compatibility

AXC F 1152 / 2152 and other PLCnext Control devices with Docker support. ARM32v7 and x86_64 images. Offline installation path available.
